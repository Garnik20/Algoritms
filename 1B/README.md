
Программа вычисляет среднее геометрическое для заданных диапазонов массива, используя логарифмы и префиксные суммы для оптимизации.

## Сдача задачи в гит

0. Создаем сами ветку с нужной нам задачей (например, `1A` - если хотим сдать задачу `A` первого контеста). Далее создаем одноименную папку.

1. Решение надо заливать в файл `main.cpp` (даже если писали в `my_greatest_sol.c`) и в него залить решение. Иначе тестирующий скрипт расстроится и упадет на третьей стадии проверки (о них ниже).

Вычисление среднего геометрического для диапазонов:
Для каждого запроса программа выполняет следующие действия:
Находит сумму логарифмов на интервале от l[i] до r[i] с помощью префиксных сумм: pref_sum[r[i]] - pref_sum[l[i] - 1].
Делит эту сумму на количество элементов в диапазоне (r[i] - l[i] + 1), получая среднее арифметическое логарифмов.
Возводит число e в полученное значение, чтобы найти среднее геометрическое на интервале.Использование exp даёт точность, достаточную для вывода с 10 знаками после запятой.
Результат выводится с точностью до 10 знаков после запятой с помощью printf("%.10f\n", ...).
