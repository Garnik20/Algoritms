# Алгоритм Краскала на обобщённом графе

Этот проект реализует алгоритм Краскала для нахождения минимального остовного дерева (MST) на графе, заданном списком рёбер. Поддерживается параметризация типом вершины и типом ребра через шаблоны C++.

---

## 🧠 Описание

Программа читает неориентированный взвешенный граф из стандартного ввода, строит его, и с помощью алгоритма Краскала вычисляет суммарный вес минимального остовного дерева.

Используется обобщённый граф (`EdgeListGraph`) и шаблонный интерфейс `IGraph`, чтобы обеспечить расширяемость и соответствие современным подходам проектирования.

---

## ⚙️ Структура

- `Edge` — структура ребра с полями `from`, `to` и `weight`.
- `IGraph` — абстрактный интерфейс графа.
- `EdgeListGraph` — конкретная реализация графа как списка рёбер.
- `Kruskal` — реализация алгоритма Краскала с DSU.
- `Input` — функция для ввода графа из stdin.
- `main` — точка входа, собирающая всё вместе.

---

## 📥 Ввод

На вход подаются:


- `n` — количество вершин.
- `m` — количество рёбер.
- Каждое ребро задано тройкой: вершина `u`, вершина `v`, вес `w`.
- Вершины нумеруются с 1, но в коде преобразуются в 0-индексацию.

---

## 📤 Вывод

Одно число — суммарный вес минимального остовного дерева.
