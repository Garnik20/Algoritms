Алгоритм реализации минимальной кучи (min-heap) выполняет следующие операции:

Вставка элемента (insert): добавляет новый элемент в конец массива и использует операцию sift_up, чтобы переместить элемент на нужное место, сохраняя свойство минимальной кучи (где каждый родитель меньше своих потомков).

Получение минимального элемента (getMin): возвращает корневой элемент (первый элемент массива), который является минимальным в min-heap.

Удаление минимального элемента (extractMin): заменяет корень (минимальный элемент) на последниий элемент, удаляет последний элемент, затем выполняет sift_down, чтобы восстановить свойства кучи.

Уменьшение ключа элемента (decreaseKey): находит элемент, уменьшает его значение и использует sift_up, чтобы переместить его вверх, чтобы восстановить свойства кучи, если есть необходимость.
