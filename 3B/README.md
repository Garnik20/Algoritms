Код реализует AVL-дерево, которое является сбалансированным бинарным деревом поиска.
Программа дополнительно поддерживает обработку запросов с использованием AVL-дерева.
Основные компоненты:
    Структура AVLNode:
        Хранит данные узла дерева:
            key — ключ узла.
            height — высота узла для балансировки дерева.
            Указатели left и right на левого и правого потомков.
        Конструктор инициализирует узел с заданным ключом.
    Класс AVLTree:
        Реализует основные операции с AVL-деревом:
            Add(int32_t key) — добавляет ключ в дерево.
            Next(int32_t key) — возвращает минимальный ключ в дереве, который больше либо равен заданному (или -1, если такого нет).
        Внутренние функции:
            Insert — вставляет узел с автоматической балансировкой.
            RotateRight, RotateLeft — выполняют правый/левый поворот для балансировки дерева.
            UpdateHeight, GetBalance — поддерживают информацию о высоте узлов и балансировке.
            FindNext — находит следующий по значению узел.
            FreeNode — рекурсивно освобождает память, занимаемую деревом.
        Деструктор (~AVLTree) освобождает всю выделенную память.

    Функция Requests:
        Обрабатывает входные запросы:
            '+' — добавление числа в AVL-дерево ( + пересчет с использованием результата предыдущего запроса если надо).
            '?' — поиск ближайшего числа, не меньшего заданного.
        Результаты запросов '?' сохраняются в вектор results.

Обеспечена автоматическая балансировка дерева после вставки с использованием поворотов (RotateLeft, RotateRight).
Узлы дерева освобождаются в деструкторе ~AVLTree.
