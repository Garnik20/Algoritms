Программа реализует дерево поиска с кучей по приоритетам (Treap).

Класс Treap
Основные свойства:
Node* root_: указатель на корневой узел дерева.
Структура Node
Узел дерева.
int32_t value: значение узла.
int32_t priority: приоритет узла (генерируется случайно).
size_t size: размер поддерева с корнем в текущем узле.
Node* left: левое поддерево.
Node* right: правое поддерево.

Методы класса Treap
Вставка элемента: void Insert(int32_t value)
Добавляет элемент с заданным значением в дерево.
Если элемент уже существует, ничего не делает.

Удаление элемента: void Deletenode(int32_t value)
Удаляет узел с заданным значением, если он существует.

Поиск элемента: bool Exists(int32_t value)
Возвращает true, если элемент существует в дереве, и false в противном случае.

Поиск следующего элемента: int32_t Next(int32_t value)
Находит минимальное значение в дереве, которое больше заданного.
Возвращает -1, если такого значения нет.


Поиск предыдущего элемента: int32_t Prev(int32_t value)
Находит максимальное значение в дереве, которое меньше заданного.
Возвращает -1, если такого значения нет.


Поиск k-го элемента: int32_t Kth(size_t prir)
Возвращает k-й элемент в дереве по порядку (нумерация с 0).
Возвращает -1, если такого элемента нет.

Private функции:
Split: Разделяет дерево на два поддерева:
left: содержит элементы меньше value.
right: содержит элементы больше или равные value.

Merge: Объединяет два дерева в одно.
UpdateSize: Обновляет размер поддерева текущего узла.
FullDell: Рекурсивно удаляет все узлы дерева (используется в деструкторе).


Insert X — вставить число X.
delete X — удалить число X.
Exists X — проверить, существует ли число X.
Next X — найти ближайшее большее число к X.
Prev X — найти ближайшее меньшее число к X.
Kth K — найти k-й элемент дерева.

Print: печатает результат
