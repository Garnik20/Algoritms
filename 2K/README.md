Класс Queue:
stack_1 и stack_2 — используются для реализации очереди. stack_1 служит для добавления элементов, а stack_2 — для удаления.
stack_1_min и stack_2_min —  стеки для отслеживания минимальных значений, чтобы обеспечить быструю операцию min.
Метод Transfer — перемещает все элементы из stack_1 в stack_2, поддерживая порядок очереди.

Mетоды:
Enqueue — добавляет элемент в очередь.
Dequeue — удаляет элемент из начала очереди.
Front — выводит элемент в начале очереди без удаления.
SizeSt — выводит текущий размер очереди.
Clear — очищает очередь.
Min — выводит минимальный элемент в очереди.
