Для решения используется трёхмерное дерево Фенвика (Fenwick Tree).
Классы и методы

Класс FenwickTree

    Атрибуты:
        cube_size_ — размер куба n.
        fenwick_ — трёхмерный массив, хранящий данные дерева Фенвика.

    Методы:
        Lsb(uint16_t x) — возвращает младший установленный бит числа x.
        Update(uint16_t x, uint16_t y, uint16_t z, int32_t delta) — добавляет delta к значению в точке (x,y,z).
        PrefixSum(int x, int y, int z) — вычисляет сумму значений от (0,0,0) до (x,y,z).
        RangeSum(uint16_t x1, uint16_t y1, uint16_t z1, uint16_t x2, uint16_t y2, uint16_t z2) — вычисляет сумму звезд в подкубе от (x1,y1,z1) до (x2,y2,z2).

Основные функции

    Requests
        Обрабатывает запросы пользователя:
            Запрос типа 1: обновление значения в точке.
            Запрос типа 2: вычисление суммы звезд в подкубе.
            Запрос типа 3: завершение программы.

    Print
        Выводит результаты для запросов типа 2.

    main
        Читает размер куба n, создает дерево Фенвика, вызывает обработчик запросов и выводит результаты.
