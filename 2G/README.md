Функция sort_by_byte:
Эта функция сортирует массив arr по значению одного байта, индексом byte_ind.
Используется подсчет частот каждого байта (0-255),потом считаются префексные суммы, чтобы определить позиции элементов.
На основе подсчитанных позиций элементы упорядочиваются в массиве output, при этом равные элементы останутся в том же порядке как и в начальном массиве.
Затем отсортированный массив копируется обратно в arr.

Функция sort_lsd:
Эта функция выполняет LSD-сортировку по байтам, начиная с младшего.
На каждом шаге вызывает sort_by_byte для очередного байта, пока все байты каждого числа не будут отсортированы.
