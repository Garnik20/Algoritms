Код разделяет массив на части с помощью функции Partittion.
Затем QuickSort рекурсивно сортирует каждую часть, пока весь массив не станет отсортированным.
В конце отсортированный массив выводится на экран.

Функция Partittion:
Делит массив на две части вокруг опорного элемента (pivot).
Все элементы, меньшие pivot, перемещаются влево, а большие — вправо.
В конце pivot устанавливается на своё окончательное место в массиве, и функция возвращает его индекс.

Функция QuickSort:
Рекурсивно сортирует массив.Выбирает случайный индекс опорного элемента, вызывает Partittion для разделения массива и затем рекурсивно вызывает себя для левой и правой частей массива.
