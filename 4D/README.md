 Класс SparseTable
    Используется для предобработки массива и выполнения запросов на нахождение второй порядковой статистики на заданных диапазонах.
    Методы:
        Конструктор SparseTable(const vector<int>& arr)
            Вход: массив arr.
            Описание:
                Вычисляет логарифмы для диапазонов.
                Инициализирует таблицы:
                    table_ — минимальные значения.
                    second_ — вторые минимальные значения.
                Заполняет Sparse Table для всех подотрезков длины 2^k.
            Сложность: O(Nlog⁡N).
        Метод SecondMin(int start, int finish)
            Вход: индексы диапазона [start,finish].
            Выход: второй минимальный элемент на диапазоне.
            Описание:
                Объединяет минимальные и вторые минимальные значения двух блоков, покрывающих диапазон.
                Возвращает второй минимальный элемент.
            Сложность: O(1).

Функции
    Input
        Вход: ссылки на массив arr и вектор запросов requests.
        Читает массив arr и диапазоны запросов.
        Преобразует диапазоны в нулевую индексацию.
    Solver
        Вход: объект SparseTable и запросы.
        Выполняет запросы с помощью метода SecondMin и выводит результаты.
