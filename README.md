Найти такое минимальное расстояние между k точками, чтобы это расстояние было максимально возможным.

Преобразование массива в расстояния:
На основе массива arr создается массив расстояний между соседними точками.

Бинарный поиск по минимальному расстоянию d:
Пытаемся найти максимальное минимальное расстояние d с использованием бинарного поиска.
Начальные границы для бинарного поиска: mid_down = 1 и mid_up = (arr[n - 1] - arr[0]) / (k - 1) — максимальное расстояние, которое может быть между k точками, равномерно распределенными между первой и последней точкой.
В каждом шаге проверяем, можно ли разделить массив на k отрезков с минимальным расстоянием d . Если можно, увеличиваем mid_down, иначе уменьшаем mid_up.

Функция is_can_for_d:
Проверяет, можно ли найти не менее k интервалов с обшим расстоянием, не менее d.
Если удалось , функция возвращает true, иначе — false.

После бинарного поиска, проверяем значения mid_down и mid_up на возможность создания k отрезков и выводим подходящее значение.
